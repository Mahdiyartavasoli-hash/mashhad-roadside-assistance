# Frontend

Static mobile-first frontend built with semantic HTML, Tailwind CSS 4 and Vanilla JavaScript.

## Build

```bash
npm install
npm run dev
npm run build
```

The production CSS is generated by Tailwind CLI. The frontend uses `/api` by default and falls back to local data if the API is unavailable.

Before launch, replace all `example.com` URLs, placeholder phone numbers, statistics, testimonials, images and brand information.
